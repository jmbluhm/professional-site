# Krengl

## Project Overview

Krengl is a group wish list and coordinated gift-giving application. It supports shared groups, reservations to prevent duplicate gifts, and rich item metadata.

## Core Functionality

### Group Coordination

Krengl enables groups of people to coordinate gift-giving by sharing wish lists within defined groups. Members can view lists, reserve items, and avoid duplicate purchases.

### Reservation System

The application includes a reservation mechanism that prevents multiple people from purchasing the same gift while maintaining privacy about who reserved each item.

### Item Management

Users can add items with rich metadata, including links, descriptions, price information, and priority indicators.

## Technical Approach

The project demonstrates end-to-end system design, including:
- User management and group permissions
- Data modeling for wish lists and reservations
- Privacy controls and visibility rules
- Production-quality implementation
